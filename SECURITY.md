# Seguridad

Este repositorio contiene solo prototipos de diseño con **datos ficticios**.
No es el sistema de producción, no tiene backend y no se conecta a ninguna base de datos ni entorno real.

Si encuentra una vulnerabilidad en estas demos, ábrala como un [aviso de seguridad de GitHub](https://docs.github.com/es/code-security/security-advisories/working-with-repository-security-advisories/responsibly-disclosing-a-security-vulnerability-in-a-github-repo) o un issue en este repositorio. No incluya credenciales ni datos reales.

No envíe secretos, archivos `.env`, tokens ni información de cooperativas o personas reales.
